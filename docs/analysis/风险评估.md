## 真机门禁

1. **板级基线**：冷启动 NSH、`ls /dev`、camera、LVGL、SD、Wi-Fi、buttons、LED、`ostest`。
2. **Agent 基线**：联网、LLM 对话、自定义 Skill 发现/调用、Tool 产生真实副作用。
3. **主动闭环**：无人输入时自动触发，执行后有 UI/语音/消息反馈，重启后恢复。
4. **容错**：断网、API 超时/限流、daemon 掉线、存储满/损坏、外设失败。
5. **性能**：冷启动、P50/P95、heap 峰值/泄漏、stack 余量、Flash/PSRAM、30-60 分钟 soak。
6. **安全**：Key 脱敏、Shell 白名单、日志无凭据、摄像头/录音有隐私说明。
7. **复现**：macOS clean clone -> build -> flash -> demo；固定 SHA、工具链和故障手册。

## 高收益技术路线

- 基础门槛之上优先完成官方明确加分项：端云/端端协作、轻量跨会话记忆、设备互联、自定义 LVGL UI。
- 借鉴 mini_memo 的接口设计，但将 UI Timer 主动提醒升级为 `cron_service + message_bus`，并保留 daemon 不可用时的本地 fallback。
- 组合 AI + 图形 + 多媒体能力，以摄像头/音频/加速度计事件驱动 Agent，而非仅由用户输入触发。
- 将资源优化、故障恢复和安全白名单作为产品能力展示，而非隐藏在文档中。

## 硬件已知限制

- ESP32-S3-EYE 无 USB-UART 桥；固件持续重启无法烧录时，按住 BOOT、按 RESET、释放 RESET、再释放 BOOT。
- v2.2 增加 GPIO3 限流电阻，但软件仍应按开漏方式驱动 LED。
- 当前 openvela 文档标注 BLE scan 可能 hard-fault、加速度计暂无 uORB、microSD 仅 1-bit、LCD 无触摸。
- 板卡具备 8 MB PSRAM 与 8 MB Flash，但视觉、音频、LVGL 和 Agent 同时启用时仍需严格预算。
