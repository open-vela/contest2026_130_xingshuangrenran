## 已确认的教程差异

1. `packages/ai_agent/defconfigs/esp32s3-eye/README.md` 的复制示例省略了 `esp32s3-eye/` 子目录；本地实际文件为 `packages/ai_agent/defconfigs/esp32s3-eye/esp32s3-eye_defconfig`，适配器按真实路径处理。
2. 官方 Linux 命令使用 `nproc`、`/dev/ttyACM*` 或 `/dev/serial/by-id`；macOS 分别替换为 `sysctl -n hw.logicalcpu` 和 `/dev/cu.*`。
3. `ai_agent` 实际依赖 manifest 中的 `frameworks/multimedia`、`frameworks/multimedia/media` 和 `frameworks/multimedia/media/pfw`；缺少其中任一项目都会导致 `media_player.h` 编译失败，环境检查现已覆盖这三项。
4. macOS 自带 Bash 版本与 GNU 工具行为不满足官方修复脚本要求；适配器固定使用 Homebrew Bash 5.3 和 GNU sed 4.10。
5. 官方 `fix_esp32s3.sh` 的 `/data` 补丁存在 raw string 匹配缺陷，已现场修正并验证实际写入；这是公共项目修改，后续单独走上游 PR。
6. ESP-WHO 指南只用于确认硬件与原厂操作，不执行其中示例作为参赛 Demo；参赛判定以 openvela + ai_agent 固件为准。
