## Markdown 适配

原聊天气泡直接通过 Compose `Text` 输出 `ChatMessage.content`，标题、粗体、
列表、引用、代码和链接均显示为原始标记。

本轮接入成熟的 Markwon `4.6.2`：

```text
AI 回复 -> Markwon -> Android TextView -> Compose AndroidView
```

支持：

- 标题与正文层级；
- 粗体、斜体和删除线；
- 有序与无序列表；
- 引用；
- 行内代码和代码块；
- 可点击链接；
- 文本选择和原有长按复制。

用户自己发送的消息继续使用纯文本，避免输入内容被意外解释为 Markdown。

## 已知警告与验证边界

- 原项目 BLE 管理器使用部分已弃用 Android Bluetooth API，当前仅产生编译
  警告，不影响 APK 生成；后续若长期维护应迁移到 Android 13 新写入接口。
- 当前没有连接 Android 真机或模拟器，因此尚未完成安装、WebSocket 对话和
  Markdown 视觉回归。
- APK 使用调试签名，适合比赛开发和演示安装；正式发布前需替换为专用发布
  证书并妥善保管密钥。
