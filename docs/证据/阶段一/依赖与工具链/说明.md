- 赛事 manifest 只声明 Linux Xtensa 预编译项目；macOS 工具链采用乐鑫同版本官方 Apple Silicon release。
- 本节记录 T1.3 当时的执行边界；后续构建和真机状态以 T1.4/T1.5 证据为准。
